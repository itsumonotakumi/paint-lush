# ペイントラッシュ！（PAINT RUSH!）

ブラウザだけで遊べる、インクで陣地を塗り合う3Dチーム対戦ゲームです。登場するのは全員忍者。現在はプロトタイプで、1ステージで撃つ・塗る・潜る操作を試せます。

**遊ぶ:** https://itsumonotakumi.github.io/paint-lush/

| 操作 | キーボード＋マウス | ゲームパッド |
| --- | --- | --- |
| 移動 | WASD | 左スティック |
| 視点 | マウス | 右スティック |
| 射撃 | 左クリック | RT |
| ジャンプ | Space | A |
| 染遁（潜る） | 左 Shift を押し続ける | LT |
| ポーズ | Esc | Start |

## 開発

```bash
npm ci --ignore-scripts
npm run dev
```

設計資料は [doc/](doc/)、素材の出典は [CREDITS.md](CREDITS.md) にあります。
