# ペイントラッシュ！（PAINT RUSH!）

ブラウザだけで遊べる、インクで陣地を塗り合う3Dチーム対戦ゲームです。登場するのは全員忍者。4対4のCPU戦「色取り合戦」と練習用の「修行場」を、PC・スマホ・タブレットで遊べます。

**遊ぶ:** https://itsumonotakumi.github.io/paint-lush/

| 操作 | キーボード＋マウス | ゲームパッド |
| --- | --- | --- |
| 移動 | WASD | 左スティック |
| 視点 | マウス | 右スティック |
| 射撃 | 左クリック | RT |
| ジャンプ | Space | A |
| 染遁（潜る） | 左 Shift を押し続ける | LT |
| 彩煙玉 | E | RB |
| 奥義 | Q | Y |
| ポーズ | Esc | Start |

スマホとタブレットでは、画面のタッチボタンで操作します。キー割り当ては設定画面で変更できます。

## 開発

```bash
npm ci --ignore-scripts
npm run dev
```

設計資料は [doc/](doc/)、素材の出典は [CREDITS.md](CREDITS.md) にあります。
